# Alaris Economy Bot

Standalone economy service for the Realm of Alaris.

## Features
- Shared Postgres integration
- Character-linked economy
- Kingdom treasuries
- Alaris currency system
- Assets and noble titles
- Shared integration with AlarisBot

DISCORD_TOKEN
DATABASE_URL
GUILD_ID
STAFF_ROLE_IDS
